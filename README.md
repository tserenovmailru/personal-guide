## Структура руководства

Этот репо — твоя персональная среда развития. Что здесь живёт:

- **`daily/YYYY-MM-DD.md`** — руководство на текущий день: одно действие, одна помидорка, один вопрос для рефлексии.
- **`weekly/W{N}.md`** — руководство на неделю: ритм, гипотеза, слоты.
- **`history/`** — архив рефлексий (файлы `YYYY-MM-DD-reflection.txt`).
- **`profile.md`** — текущий RCS-профиль (ступень, bottleneck, неудовлетворённость).
- **`worldview.md`** — нарративная дуга: где сейчас, куда двигаемся.
- **`methods.md`** — активные методы под текущий bottleneck.

## Цикл работы

**Каждый день** — открыть `daily/<сегодня>.md`, прочитать одно действие, закрыть слот (25 мин), добавить одну строку в `history/`.

**Каждую неделю** (понедельник утром) — руководство пересобирается автоматически, если ты добавил рефлексии.

## Рефлексия — главное

Рефлексия — это текстовый файл в `history/YYYY-MM-DD-reflection.txt`. Достаточно одного абзаца после каждого дня:

```
Что закрыл: трекер включил на 25 мин (тему не помню)
Что помешало: звонок на работе
Что помогло: открыл страницу с заданиями сразу после завтрака
```

## Команды

- `/personal-guide-render` — пересобрать все файлы руководства по твоему актуальному профилю.
- Просто пиши рефлексии в `history/` — Портной заметит и адаптирует.
