## Что здесь

Этот репо — твоя персональная среда развития. Живут здесь:

- **`daily/YYYY-MM-DD.md`** — руководство на текущий день: одно действие, один слот, одна рефлексия.
- **`weekly/W{N}.md`** — руководство на неделю: ритм, гипотеза, слоты.
- **`history/`** — архив рефлексий (файлы `YYYY-MM-DD-reflection.txt`).
- **`profile.md`** — твой текущий RCS-профиль (ступень, bottleneck, неудовлетворённости).
- **`worldview.md`** — нарративная дуга: где сейчас, куда двигаемся.
- **`methods.md`** — активный метод под текущий bottleneck.

---

## Цикл работы

**Каждый день:**
1. Открой `daily/<сегодня>.md`.
2. Прочитай одно действие.
3. Закрой один слот (25 мин с трекером).
4. Добавь одну строку в `history/YYYY-MM-DD-reflection.txt`: что закрыл, что мешало / помогало.

**Каждую неделю (понедельник):**
- Руководство пересобирается автоматически под актуальный RCS-профиль.

## Рефлексия

Рефлексия — это текстовый файл в `history/YYYY-MM-DD-reflection.txt`. Достаточно одного абзаца:

```
19.05: закрыл слот 25 мин (тема: основы). Мешало — приложение на телефоне, помогла — музыка без слов.
```

Портной читает эти рефлексии при следующем рендере и адаптирует контент под них.

## Важно

На этой ступени нет требований к качеству, систематичности или методичности. Одна помидорка в день — уже победа. Пропустить день — не провал; провал — решить, что это кончено.
