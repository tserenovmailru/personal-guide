## Структура этого руководства

Это твоя персональная среда развития. Здесь живут:

- **`daily/YYYY-MM-DD.md`** — руководство на текущий день: одно действие, один слот, один вопрос для рефлексии.
- **`weekly/W{N}.md`** — руководство на неделю: ритм, гипотеза, слоты.
- **`history/`** — архив рефлексий (файлы `YYYY-MM-DD-reflection.txt`).
- **`profile.md`** — твой текущий RCS-профиль (ступень, bottleneck, метрики).
- **`worldview.md`** — нарративная дуга: где ты сейчас, куда двигаешься.
- **`methods.md`** — активный метод под текущий bottleneck.

## Цикл работы

**Каждый день:**
1. Открой `daily/<сегодня>.md`.
2. Прочитай задачу дня.
3. Закрой один слот (25 мин с трекером).
4. Добавь одну строку в `history/YYYY-MM-DD-reflection.txt`.

**Каждую неделю (в понедельник):**
- Руководство пересобирается автоматически по актуальному профилю.

## Что такое слот

Слот = один сеанс 25 минут (помидорка) с включённым трекером. Не нужно:
- Планировать весь день.
- Достигать результатов.
- Быть идеальным.

Нужно только:
- Включить трекер.
- Заниматься 25 минут.
- Остановить трекер.

## Рефлексия

После каждого дня — одна строка (абзац) в файл `history/YYYY-MM-DD-reflection.txt`:

**Что закрыл / не закрыл сегодня?**
**Что мешало / помогало?**

Это всё. Портной читает рефлексии и адаптирует контент под них.

## Критерий успеха на горизонт 2–3 недель

**Одно:** ≥3 слота суммарно за 2 недели, зафиксированы в трекере. Не качество, не методы — просто факт начала.

Когда выполнишь это — переходишь на Ступень 2 (Практикующий).
